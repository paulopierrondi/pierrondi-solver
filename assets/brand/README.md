# Brand asset index

This directory is the production asset pack for `PIERRONDI / LABS` and
`pierrondi-solver`.

| Asset | Use |
| --- | --- |
| `pierrondi-labs-mark.svg` | Umbrella avatar and compact signature |
| `pierrondi-labs-lockup.svg` | Master brand lockup |
| `pierrondi-solver-mark.svg` | Product icon |
| `github-profile-banner.svg` | GitHub profile README header |
| `github-social-preview.svg` | Standalone vector repository preview |
| `github-social-preview-overlay.svg` | Editable overlay used for the raster preview |
| `github-social-preview.jpg` | GitHub Settings → Social preview upload |
| `social-preview-background-source.png` | Original generated raster backdrop |
| `social-preview-background.jpg` | Optimized working background |
| `GENERATION.md` | Reproducible prompt and generation record |

The raster background was generated with OpenAI's built-in image generation
tool. All marks, typography, grids, lockups, and final layouts are deterministic
SVG assets. See [`../../docs/BRAND.md`](../../docs/BRAND.md) for rules and
extension guidance.
