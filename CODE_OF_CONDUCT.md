# Community code of conduct

We want this project to be technically rigorous, welcoming, and safe.

## Expected behavior

- Be respectful and specific.
- Critique ideas and code, not people.
- Share reproducible evidence.
- Protect private data and credentials.
- Respect the project's authorized-use boundary.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, credential exposure, deliberate
misrepresentation, and requests for abusive or unauthorized use are not
accepted.

## Enforcement

Maintainers may edit, remove, or reject contributions and interactions that
violate these standards. Serious or repeated violations may result in a ban
from project spaces.

For sensitive conduct concerns, use the repository's private vulnerability
reporting channel and clearly label the report as a community conduct matter.
